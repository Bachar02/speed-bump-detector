## Pipeline

Raw data in `bumps-dataset/` is never modified. Everything in `data/` is regenerated by:

```bash
python src/data/clean.py          # dedup + strip metadata  -> data/clean/images, manifest.csv
python src/data/split.py          # scene-grouped split      (groups in src/data/scene_groups.py)
python src/data/autolabel.py --model <path-to>/grounding-dino-tiny   # draft boxes (CPU: ~1 h)
python src/data/negatives.py      # RDD2022 backgrounds      -> data/negatives/
python src/data/merge_labels.py   # manual + reviewed drafts -> data/clean/labels, label_review.csv
python src/data/build_yolo.py     # -> data/yolo/ + bumps.yaml
```

`src/data/review_sheet.py` draws boxes onto contact sheets for quick visual review.

### Finishing the labels
1. Import `data/clean/images` + `data/clean/labels` into CVAT (YOLO 1.1 format).
2. Filter by `label_review.csv` status `needs_fix` / `needs_label`, then draw or fix the boxes,
   following [docs/labeling_guidelines.md](docs/labeling_guidelines.md).
3. Export to YOLO, copy the `.txt` files into `data/clean/labels_manual/`, then rerun
   `merge_labels.py` and `build_yolo.py`.

### Train the baseline
```bash
pip install -r requirements.txt
yolo detect train model=yolo11n.pt data=data/yolo/bumps.yaml imgsz=640 epochs=150 batch=8 flipud=0
```
